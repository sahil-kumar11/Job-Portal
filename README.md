# 📌 Overview

The **Job Portal System** is designed to simplify the online recruitment process for both employers and job seekers.  
Recruiters can post jobs, manage applicants, and review applications, while users can search and apply for jobs seamlessly.

This platform provides:

- Secure authentication system
- Recruiter approval workflow
- Job posting & management
- Job application system
- Candidate tracking
- Role-based dashboards
- Professional UI experience

# ⚙️ Installation Guide

## 1️⃣ Clone Repository

```bash
git clone https://github.com/sahil-kumar11/job-portal-system.git
cd job-portal-system
```

---

## 2️⃣ Create Virtual Environment

### Windows
```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / Mac
```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 4️⃣ Apply Migrations

```bash
python manage.py migrate
```

---

## 5️⃣ Create Superuser

```bash
python manage.py createsuperuser
```

---

## 6️⃣ Run Development Server

```bash
python manage.py runserver
```

Open your browser:

```bash
http://127.0.0.1:8000/
```
